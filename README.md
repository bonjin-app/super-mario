# PIPO JUMP 🤖

오리지널 캐릭터 플랫폼 액션 게임 (HTML5 Canvas, 60fps)
모든 캐릭터·스프라이트·사운드가 원작 없이 직접 디자인/구현했습니다.

## 실행

```bash
open index.html
# 또는
npx serve .   # → http://localhost:3000
```

## 조작법

| 키 | 기능 |
|---|---|
| ← → / A D | 이동 |
| ↑ / W / X / Space | 점프 (길게 누르면 높이) |
| Shift / Z | 런 |
| F / K | 화염구 (불꽃 파워업 보유 시, 최대 2발) |
| Enter | 시작 / 확인 |
| P / Esc | 일시정지 |
| M | 사운드 on/off |
| B | BGM on/off |

## 선택 가능한 히어로 (타이틀 화면에서 ←→)

| 히어로 | 특징 |
|---|---|
| **PIP** (로봇) | 균형형 |
| **MOCHI** (고양이) | 빠름 / 점프 낮음 |
| **BOLT** (여우) | 느림 / 점프 높음 |

## 게임 내용

- 타이틀: 캐릭터 선택 → 3종 코스 로테이션 (1-1 / 1-2 / 1-3)
- ? 블록(코인/버섯/불꽃/별), 벽돌 깨기, 파이프, 구덩이, 계단
- 적: **PUFF** (밟기), **SHELLY** (밟으면 쉘 → 쉘 차기로 다른 적 처치)
- 파워업: 버섯(성장), **불꽃(F키로 화염구 발사, 최대 2발)**, 별(무적)
- 데미지: 대형일 때 적 접촉 → 축소(무적 프레임 부여), 소형일 때 → 사망 (원작 방식)
- 연속 밟기 콤보 (100 → 8000), **100코인 = 1UP**
- 깃대(높이에 따라 100~5000점) → 성 → 다음 레벨, 타임 400, 라이프 3
- 하이스코어 localStorage 저장 (타이틀 TOP 표시)

## 부드러운 조작감 (고도화) 구현

- 2x 슈퍼샘플링 + 서브픽셀 렌더링 (부드러운 움직임)
- 카메라 이징 (lerp, 뒤로 스크롤 없음)
- 코요테 타임 + 점프 버퍼 (점프 타이밍 관대)
- 스퀴치 & 스트레치 점프/착지 애니메이션
- 착지/러닝/코인/벽돌 파티클, 점수 팝업 페이드
- 구름 패럴랙스 + 벽돌 깨기 화면 셰이크
- WebAudio 오리지널 체iptune BGM (Am-F-C-G 루프) + 8비트 효과음
- 원작(1985) 속도감: 걷기 1.4px/f · 런 2.7px/f · 완만한 가속/미끄러짐
